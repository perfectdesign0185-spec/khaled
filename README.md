# معرض أعمال خالد عمر | Khaled Omar Portfolio 🎨

موقع شخصي ومعرض أعمال تفاعلي احترافي للمصمم الجرافيكي **خالد عمر**، مصمم ومبني باستخدام React و Vite و Tailwind CSS و Supabase.

---

## 🚀 المميزات (Features)

- ✨ **واجهة مستخدم عصرية وسريعة (Ultra-fast UI):** متجاوبة بالكامل مع جميع الشاشات (Responsive Design).
- 🖼️ **معرض أعمال متكامل (Dynamic Portfolio):** تصنيفات مخصصة (سوشيال ميديا، متاجر إلكترونية، مطبوعات، هوية بصرية).
- ⚡ **تحميل صور فائق السرعة:** مدمج بتقنيات التحميل المسبق الذكي (Smart Preloading) ودعم صيغة WebP.
- 🔍 **نافذة عرض الصور (Interactive Lightbox):** تنقل سلس وتكبير عالي الجودة مع دعم اختصارات الكيبورد.
- 🛠️ **لوحة تحكم إدارية (Admin Dashboard):** لإضافة وتعديل وحذف الأعمال والصور والبنرات بسهولة.
- 🗄️ **قاعدة بيانات سحابية (Supabase DB & Storage):** لحفظ وتحديث البيانات والصور بشكل فوري.

---

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Frontend:** React 19, TypeScript, Vite
- **Styling:** Tailwind CSS, Lucide Icons
- **Backend / DB:** Supabase (Database + Storage)
- **Deployment:** Netlify Ready (`netlify.toml` + `_redirects`)

---

## 💻 التشغيل محلياً (Local Development)

### 1. المتطلبات:
- [Node.js](https://nodejs.org/) (إصدار 18 أو أحدث)

### 2. تثبيت الحزم:
```bash
npm install
```

### 3. إعداد المتغيرات البيئية (Environment Variables):
قم بإنشاء ملف `.env` بناءً على `.env.example`:
```env
VITE_SUPABASE_URL="your-supabase-url"
VITE_SUPABASE_ANON_KEY="your-supabase-anon-key"
```

### 4. تشغيل خادم التطوير:
```bash
npm run dev
```

---

## 📦 البناء والإنتاج (Build & Deploy)

لبناء نسخة الإنتاج:
```bash
npm run build
```
سيتم إنشاء ملفات الموقع الجاهزة داخل مجلد `dist/`.
